"Exercícios de Web Security" é um livro gratuito com uma coleção de exercícios sobre web security. O livro conta com
exercícios com falhas de segurança em código e também com falhas de segurança de arquitetura (design).

Você pode ler o livro gratuitamente aqui: <https://websec.freedev.com.br/>

- Repositório: <https://github.com/freedev-org/websec>
- DOI: [10.5281/zenodo.23853943](https://doi.org/10.5281/zenodo.23853943)
